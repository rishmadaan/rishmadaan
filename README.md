## Start here

- **[anyscribe](https://github.com/rishmadaan/anyscribe)**: turn YouTube, Instagram and audio into searchable notes, including Hindi and Hinglish; works as an MCP server so your agent can "watch" a video
- **[gitstow](https://github.com/rishmadaan/gitstow)**: keep every code project you learn from organized and up to date, for you and your agents ([gitstow.com](https://gitstow.com))
- **[talktomebaby](https://github.com/rishmadaan/talktomebaby)**: a CLI that speaks your coding agent's replies aloud, plus the Speaking Editor read-aloud engine for VS Code

## More

- **[Speaking Editor](https://github.com/rishmadaan/speaking-editor)**: hear your Obsidian notes read aloud, each word highlighted as it is spoken, click any word to jump there
